# Arquitetura do Projeto

## Objetivo

O Data Intelligence Assistant tem como objetivo automatizar análises de dados e geração de insights utilizando Python e Inteligência Artificial.

## Estrutura

### Data

- raw: dados brutos
- processed: dados tratados
- reports: relatórios gerados

### Source

- src/: regras de negócio
- tests/: testes automatizados
