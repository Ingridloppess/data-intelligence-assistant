# Data Intelligence Assistant

Projeto de automação de indicadores econômicos utilizando:

- Python
- N8N
- APIs Públicas
- Google Sheets
- GitHub

## Objetivo

Automatizar a coleta, tratamento, análise e envio de relatórios econômicos.

## Tecnologias

- Python
- N8N
- Pandas
- Google Sheets
- API Banco Central
- API IBGE 

## Limitações do Ambiente

O componente de orquestração via N8N não foi configurado durante o desenvolvimento inicial devido a restrições de instalação do ambiente corporativo.

O projeto foi estruturado para futura integração com:

- N8N Community Edition (ambiente local)
- N8N Cloud

Todos os componentes Python foram desenvolvidos de forma desacoplada, permitindo posterior orquestração sem alterações significativas na lógica de negócio.
