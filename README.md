# Data Intelligence Assistant

Projeto de automação de indicadores econômicos utilizando:

- Python
- N8N
- APIs Públicas
- Google Sheets
- GitHub

## Objetivo

Automatizar a coleta, tratamento, análise e envio de relatórios econômicos.

## Tecnologias

- Python
- N8N
- Pandas
- Google Sheets
- API Banco Central
- API IBGE
